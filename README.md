# Глубина 3D

3D подводная выживалка на Rust + macroquad. Всё своё: мир, существа, транспорт, постройки.

## Запуск
1. Поставь Rust: https://rustup.rs
2. В папке проекта: `cargo run --release`
(на Linux могут понадобиться `libx11-dev libxi-dev libgl1-mesa-dev libasound2-dev`)

## Цель
В каждом из 4 биомов лежит ядро. Собери все 4 и построй на базе Резонатор.

## Биомы
- **Солнечные отмели** (~20 м): кораллы-веера, трубчатые кораллы, стайки рыб. Медь, титан, кварц.
- **Стеблевой лес** (~85 м): гигантские светящиеся стебли, мирные парусники. Литий, титан.
- **Поющие кристаллы** (~140 м): пульсирующие кристаллы, хищные клешнеспины. Кристалл, кварц.
- **Пепельная бездна** (~265 м): жерла, шпили, мракозубы. Магмит. Без Кита туда не попасть.

## Управление
- Мышь — смотреть, WASD — плыть, Space/Ctrl — вверх/вниз, Shift — рывок
- E — собрать / забрать ядро / сесть в транспорт / выйти
- Q — сонар (подсвечивает ядра, ближайшие ресурсы, базу и плот)
- Tab — крафт снаряжения и транспорта
- B — стройка: выбираешь модуль, ЛКМ/F — поставить, R — повернуть
- X — разобрать модуль под прицелом (ресурсы возвращаются)
- Esc — отпустить мышь, H — скрыть подсказки

## Выживание
- Кислород пополняется на поверхности, в транспорте и в отсеках базы, если рядом стоит Генератор.
- Ниже предела костюма или корпуса давление жрёт здоровье/корпус.
- После смерти очнёшься в запитанном Отсеке (или на плоту), потеряв половину груза.

## Транспорт (собирается у Верфи)
- **Скат** — быстрая одноместная подлодка, нос следует за мышью, до 200 м.
- **Кит** — тяжёлая подлодка, A/D — руль, W/S — тяга, до 420 м. Внутри всегда есть воздух.

## Постройки
Фундамент, Коридор, Отсек, Обзорный купол, Генератор, Прожектор, Опора, Верфь, Резонатор.

## Код
- `src/world.rs` — рельеф, биомы, флора, ресурсы, ядра
- `src/game.rs` — игрок, база, транспорт, существа, крафт
- `src/render.rs` — свет и туман, отрисовка всего, интерфейс
- `src/main.rs` — управление и главный цикл
